# 🌊 改變中的海 — 互動闖關

一份結合**愛學網影片**的海洋與地質永續教育互動網頁，為國小高年級設計，呼應教育部「永續發展」主題。
主軸：**大自然的雕刻（野柳女王頭風化）× 人類的足跡（海洋污染、氣候變遷）**。

## ▶️ 直接遊玩

開啟 [`index.html`](index.html) 即可（單一檔案、免安裝、可離線）。
若已啟用 GitHub Pages，亦可直接用網址在手機／電腦上遊玩。

## 🎮 闖關流程

採「**看影片 → 闖關 → 再看影片 → 再闖關**」三段式：

1. 📺 **海洋篇** — 看《海灘偵察記》→ 看片驗證 → ①海洋抽抽樂 ②珊瑚白化實驗
2. 📺 **野柳篇** — 看《岩石的風化作用》→ 看片驗證 → ③野柳抽抽樂 ④地景連連看
3. 🧩 **統整篇** — ⑤兩種改變分類 ⑥海與岩循環 ⑦永續宣言

特色：即時計分（答對 +10 / 答錯 −5）、結算分級、配對變色、永續行動宣言卡。
